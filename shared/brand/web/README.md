# Web Logo Exports

Derived from the supplied SVG files in `../logos/`. The originals are unchanged.
The web SVGs preserve the artwork and its proportions, remove the export
background, and crop excess artboard space with a small clear margin.

- Horizontal: page headers and quiz/results branding.
- Vertical: centered landing-page branding.
- Type: business-page footer.
- Mark: loading indicator, browser-tab icons, and the home-screen icon.

The square icons retain the original mark's violet background. The root
`favicon.ico` contains 16, 32, and 48 pixel exports of that same mark.

`proof-horizontal-email.png` is a 600px raster export of the horizontal logo
on Deep Violet. It is sent as an inline attachment for email-client support.
